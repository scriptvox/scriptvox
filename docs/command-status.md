# Command status

What each command is known to do, so that a report cannot claim more. `crates/scriptvox/tests/docs.rs` fails when a command has no row, or a row has no command. The state itself is written by hand, and a person or agent updates it after a run.

- **Verified**: a real run on real input ended as the command promises.
- **Partial**: real runs ended well, and a named part is not run or has a known fault.
- **Unverified**: only tests or a plan ran.

"Sweep" is one run of each command with no key, in a scratch project, on 7 Nov 2026 (`docs/specs/command-status.md`). No person watched or listened in any row: a pass means that gates and frames read by eye agree.

# P2-001: generator rows (provider contract v2)

> 5 Nov 2026: `--commercial` is deleted (`docs/specs/commercial-note.md`). Text below about it is history.
>
> 7 Nov 2026: gateway `replicate` is removed from the valid list, because it has no runner. A row that names it now fails when it loads, and `generator_errors` names the fix. G138 adds it back with a runner. Text below about it is history.

- `registry/generators.toml` holds generative video rows: gateway (fal, replicate), text to video and image to video
  endpoints, durations, aspects, a per-second price, the page the price was read from and the day, the result field
  with the video URL, the download hosts, and the output terms.
- `src/generators.rs` loads and validates rows. Every problem comes back as one line that says the fix. A row that
  fails validation is never used. `SCRIPTVOX_GENERATORS` points at another file (tests, mirrors).
- `price = "exact"` when the provider page states this per-second price for the model; `"base"` when a per-second price
  is stated but the page does not say if resolution or duration changes it.
- `durations` lists only values a provider page states. `commercial = false` until the model licence is checked, so
  `--commercial` refuses these rows.
- First rows (fal pricing page, 2 Nov 2026): Kling 2.6 Pro $0.07/s exact (5 or 10 s), MiniMax H3 Max Turbo $0.025/s
  base (5 s), Grok Imagine $0.05/s base (6 s). Seedance is priced per token on fal and waits for a per-second rule.
- Keys: `fal` (`FAL_KEY`) and `replicate` (`REPLICATE_API_TOKEN`). The redactor now reads the one key table
  (`keys::PROVIDERS`), so a new provider key is hidden from output the day it is added; a test checks this.
- `scriptvox providers` lists `generators` and `generator_errors`.
- Not in this ticket: submit, poll, download (P2-002); generated scenes in the brief and plan prices (P2-003).
- Tests: shipped rows valid; a bad row gives each fix line; duration choice and cost rounding up to the cent;
  providers output; a broken row file is reported and its row is not used; every key variable is redacted.

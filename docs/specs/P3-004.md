# P3-004: re-voice and translate (`base_video`)

No translate command: the agent writes the translation. The flow is `scriptvox analyze <video> --transcript` (source
text), the agent writes the new script, then `make` with brief field `base_video: "<file in the project>"` and the
target `lang` (and `duration` set to the source length to keep the cut). The base video plays from the start under
the new narration; its own sound is dropped; new captions are burned in. `base_video` replaces media, stock and
scenes (exit 2 if combined).

Measured 2 Nov 2026: the 6.8 s Arabic open-model video, transcribed (17 of 17 words), re-voiced in English with the
open voice and a generated bed: 12.7 s, $0, voice slowed 15% by the fitter to fill the length. Limit seen: the source
had burned-in Arabic captions, so the new English captions overlap them. Use a source without burned captions; for a
scriptvox video, `scriptvox resume <run_id> --brief` with the translated script rebuilds from the clean clips instead.
Test: a test video with its own sound plays under a stub voice as one shot; `base_video` with `stock` is exit 2.

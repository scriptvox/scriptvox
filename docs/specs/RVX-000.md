# RVX-000: Skeleton, envelope, exit table, push block

Source: own design, PLAN-R1 §2.3 and §3.

## Behaviour
- `scriptvox --version --json`: exit 0, one JSON envelope with `schema:"scriptvox.result/v1"`, `ok:true`, `version`, `proto:"1.0"`, `ffmpeg_pin` (null until RVX-018).
- `scriptvox status --json`: exit 0, envelope with `runs:[]` (no run store until RVX-015).
- Unknown command: exit 2, envelope with `error.code` `SVX_USAGE` and a `fix`.
- When stdout is not a TTY the envelope is printed even without `--json`. Logs go to stderr.
- Exit codes: one table in `crates/scriptvox/src/exit.rs`, locked by an insta snapshot.
- `git push` is refused by `.git/hooks/pre-push`.

## Deliberate simplifications
- No `registry.rs`: the clap tree is the registry until schema and skill generation (RVX-025, RVX-032) need more.
- Startup test limit is 200 ms (target about 50 ms) so a busy shared machine does not make it flaky. The measured number is printed by the test.

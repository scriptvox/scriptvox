# RVX-001: local licence and quality gates

- `just licenses`: `cargo deny check licenses bans`, `reuse lint`, and the media provenance check. Each media file needs `<file>.license` with a `Source: ` line.
- `just check` adds `ruff check python`. `just ci` runs check, licenses and test.
- Git hooks live in the tracked `hooks/` dir (`git config core.hooksPath hooks`). `commit-msg` refuses a commit with no DCO sign-off. `pre-commit` refuses staged secret keys. `pre-push` refuses every push; it is local only and is not in the public tree (`scripts/public-tree.sh`).
- `.claude/settings.json` denies edits in the cloned repos. Reads are allowed (`docs/specs/idea-reuse.md`).

Deliberate simplifications:
- Plain git hooks instead of the pre-commit framework: there is no extra tool to install.
- `pip-licenses` waits for the first Python dependency. `about.toml` (third-party notices) waits for the first release.
- `assets/fonts/OFL.txt` waits for the ticket that adds the first font.

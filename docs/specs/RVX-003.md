# RVX-003: agent-mode guard

Idea source: HyperFrames `cli/src/telemetry/agent_runtime.ts` (Apache-2.0), read for the env-var idea only.

- `agent_mode::detect`: on when `CLAUDECODE`, `CLAUDE_CODE_ENTRYPOINT` or `CI` holds a value other than empty, `0` or `false`. Ours adds the `0`/`false` rule, so `CI=false` in a dev shell does not switch agent mode on.
- Agent mode or no TTY: JSON envelope, and clap colours off (no ANSI). Agent mode does not follow from a missing TTY.
- `status` reports `agent_mode`.
- `Redactor`: every stdout and stderr line passes through it. Values of `ELEVENLABS_API_KEY`, `PEXELS_API_KEY` and `PIXABAY_API_KEY` (8 characters or more) become `***`. Longest key first.
- Tests walk every clap subcommand with `CLAUDECODE=1`: no ESC byte on either stream, and the last stdout line is an envelope. Tests clear the agent vars, so the result does not depend on the caller.

Deferred: SIGPIPE and EPIPE handling goes to RVX-016 (detach), where a broken pipe detaches the run. The keys.toml values join the redactor in RVX-020.

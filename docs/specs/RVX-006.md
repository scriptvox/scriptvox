# RVX-006: filtergraph paths and libass fonts

- Generated files use fixed relative names, and FFmpeg runs with the run folder as cwd. No escaping is needed for them.
- `filter_path` (user paths only): level 1 escapes `\ ' :`, then level 2 escapes `\ ' [ ] , ;`. On Windows `\` becomes `/`. On Unix `\` is a legal file-name character, so it is escaped and kept. The property test found this case.
- `ass_filter` is the only subtitle filter builder, and it always sets `fontsdir`.
- `fontconfig()` writes a minimal `FONTCONFIG_FILE` that sees only our fonts, with XML-escaped paths.
- Fonts: static Regular and Bold of Noto Sans, Noto Sans Arabic and Noto Naskh Arabic (OFL-1.1). Variable fonts lost their bold weight on Windows (spike). The font folder holds font files only, because `fontsdir` loads every file in it.
- `tests/filterpath_prop.rs`: 24 random paths (drive colon, space, quote, brackets, comma, semicolon, backslash, Arabic) each go through a real FFmpeg parse, and libass must open the file. `SCRIPTVOX_FFMPEG` (set by the justfile to the pinned build) enables the test.

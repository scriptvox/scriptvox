# RVX-008: text lint at plan time

Ideas: HF #5885, MPT #1205, MGL #1173, OM #819 (CAP gap 1). Code is ScriptVox's own (`src/textlint.rs`).

- Runs on the spoken text (pause tags removed) inside `make`, before TTS, stock or render. A finding gives exit 3 with its code, detail and fix, and all findings are in `findings`.
- `SVX_FONT_COVERAGE`: characters with no glyph in the embedded caption fonts (Noto Sans, Noto Sans Arabic; checked through each font's cmap with read-fonts). Emoji, CJK, Hebrew and similar would render as boxes. Up to 12 are listed with code points.
- `SVX_RTL_SPLIT`: 3 or more single Arabic letters in a row, separated by spaces (letter-by-letter text cannot join).
- `SVX_RTL_PRESHAPED`: Arabic presentation forms (U+FB50 to U+FDFF, U+FE70 to U+FEFF), pre-shaped text pasted from a PDF or an old app (the MGL #1173 class).
- Tests: clean mixed Arabic and Latin passes; each code fires on its case; `plan --brief fixtures/briefs/ar-latin-font.json` gives exit 3 `SVX_FONT_COVERAGE` with a fix; a proptest of 128 random Arabic word strings gives no findings.

Simplification: the ticket named unicode-bidi, unicode-linebreak, ttf-parser and fontdb. None is needed: read-fonts (already a dependency) gives the cmap, and harfrust already shapes RTL in the caption engine.

# RVX-009: RVX-RPC host and embedded worker

- Worker (`python/scriptvox_worker/rpc.py`, stdlib only): `hello` (proto major check, tool manifests), `tool.call`, `cancel`, `shutdown`, `event` notifications. `serve()` dups the real stdout for protocol lines, then points fd 1, `print` and logging at stderr. A test proves a tool's `print()` never reaches protocol stdout.
- Host (`src/rpc.rs`): a reader thread per worker. A non-JSON line or EOF kills the worker and gives `-32099 worker_crashed`. No answer within `timeout` (300 s) gives `-32098 worker_timeout`. A different proto major gives `-32002`, and `scriptvox worker` maps it to exit 1 with `SVX_PROTO_MISMATCH`. Worker-to-core requests get "unknown method" until RVX-028 adds `ledger.reserve`.
- Embedded worker (`src/provision.rs`): the binary carries the worker files (a test fails if a `.py` file is missing from the list), unpacks them into `<data>/worker/<version>-<fnv hash>/` with a temp folder and a rename, and starts `uv run --frozen --no-dev --python 3.12`. `SCRIPTVOX_WORKER_SRC` uses a checkout instead (editable). `SCRIPTVOX_UV` overrides `uv`.
- Contract: `fixtures/contract/*.jsonl` replay over a real pipe (`tests/contract.rs`) and in-process (`python/tests/test_contract.py`). `just test` runs both.
- `hello` round trip on this WSL: 25 ms with a warm uv environment.
- `demo` never starts the worker: the empty-PATH demo test has no `uv`, and it still passes.

Deferred: `schemas/rpc/` generation goes with the `schema` command (RVX-025).

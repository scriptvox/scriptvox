# RVX-011: pause tags

- `pauses::parse` / `strip` (`src/pauses.rs`): rules from MoneyPrinterTurbo (MIT, see `docs/provenance/mpt-pauses.md`) plus Arabic keywords, units and digits. `[pause 1.5]`, `(silence: 800ms)`, `[توقف ١٫٥ ثانية]`.
- `make`: one TTS call per speech segment. Each clip is decoded to 24 kHz mono WAV, its trailing silence is trimmed (50 ms kept), and silences are generated by sample count. The concat gives `voice.wav`. Word times move by each segment's start. Captions never show the tags, and a pause of 0.6 s or more starts a new caption page.
- Contract change: the core creates a tool's `out_dir` before the call.
- Tests: parser units (EN, AR, clamp, merge, invalid), and `tests/make.rs` with stub sine segments: `silencedetect` measures 1.500 s (within 5 ms) and the SRT shows the shifted times.
- Live (Edge, Arabic): a `[توقف ١٫٥ ثانية]` tag gives a 1.74 s gap the listener hears. The extra 0.24 s is the kept 50 ms plus Edge's leading silence on the next clip. That leading silence is not trimmed, because trimming it would move the word times.

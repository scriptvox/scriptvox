# RVX-012: duration fitter

Idea: OpenMontage #396 (narration came out 1.94x its target). Rules and code are ScriptVox's own (`src/fit.rs`).

- `make --duration S` fits the narration before any render. The video is exactly S seconds.
- Before TTS, an estimate (2.6 words/s English, 2.1 Arabic, plus pauses) stops only clear misses (ratio outside 0.55 to 1.7) with exit 3. No provider call is made.
- After TTS, the ladder:
  1. within 3%: keep;
  2. within 8%: `atempo` (chained below 0.5), word times scaled;
  3. within 50%: one TTS retry with the engine's own speaking rate (Edge `rate`, sounds natural), then `atempo` for what is left if it is within 16%;
  4. else exit 3 `SVX_NEEDS_SHORTER_SCRIPT` or `SVX_NEEDS_LONGER_SCRIPT` with "Cut about N words" or "Add about N words". Nothing is rendered.
- `explain` records the fit step (`fit: TTS rate +26%`, `atempo 1.053`).
- Tests: ladder units, the 1.94x case (cut 68 of 140 words), precheck, `atempo` chain; `tests/make.rs`: keep, atempo (fitted audio within 20 ms), far too long (no video), clear miss before TTS (a stub that would fail proves TTS never ran), and a retry that stays off (exit 3, not a panic).
- Live: 10.1 s narration for an 8 s target became a +26% rate retry that landed within 3%.

Deferred: per-scene fitting (±0.5 s per scene) comes with scenes in the brief (RVX-013 and later). v0.1 fits the whole narration.

# RVX-013: own media as the shot list

- `make --media dir`: your clips and stills are the visuals, in natural file-name order (clip2 before clip10). Shots are cut on caption pages, so cuts change with the speech. When there are more files than pages, the longest shots split (never below 1.2 s), so every file appears. When there are more pages than files, the files cycle.
- Clips: centre crop to fill the frame, frame rate set to 30, a clip at least 70% of its shot plays slower to fill it (`setpts`, see `short-clip.md`), a shorter one holds its last frame, and clip audio is dropped (narration only). Stills: a Ken Burns push-in from 100% to 110%, rendered at 2x for smooth motion.
- One FFmpeg graph builds the visual track, then the captions and the narration.
- Path-root check (idea from MPT #1336): the folder and every file in it must resolve inside the project folder. A symlink to the outside is refused. Exit 1 with `SVX_PATH_OUTSIDE_ROOT`. A missing or empty folder fails before TTS, with a fix.
- `scriptvox media add dir`: the same check, then ffprobe size and duration per file, written to `.scriptvox/media.json`, with a `next` hint.
- `metrics.shots` reports the shot count.
- Fixtures (`fixtures/media/`, 236 KB): 2 clips and 2 stills generated with FFmpeg lavfi (CC0).
- Tests: natural order, shot cuts, spreading, cycling, outside root (unit and CLI), every file used (4 shots from 4 files), missing and empty folders fail before TTS.

Deferred: crossfades between shots, ducked clip audio, and an own-media golden (with crossfades, RVX-023). Clip audio came on 10 Nov 2026: scene `sound`, see `scene-clip-sound.md`.

## Update (night of 2 Nov): crossfades

Shots now crossfade (0.25 s, `xfade=fade`). Every shot except the last renders 0.25 s longer, and shot i+1 starts where shot i ends in the timeline, so the total length, the audio and the captions do not move (320 of 320 frames, drift 0.7 ms on the own-media sample).

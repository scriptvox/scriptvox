# RVX-018: provisioner from toolchain.lock

- `toolchain.lock` (compiled in): FFmpeg n8.1.3 from the BtbN month-end tag `autobuild-2026-10-31-12-59` (gpl; linux-x86_64, linux-aarch64, windows-x86_64) and uv 0.13.1 (19 days old; the plan's 0.13.6 was only 6 days old). Each pin has the URL, sha256, size, licence, strip depth and binaries. `SCRIPTVOX_TOOLCHAIN` points at another lock file (tests, mirrors).
- `provision::install`: ureq (rustls with the platform verifier) streams to `.part` while hashing with sha256. A mismatch deletes the file and gives `SVX_CHECKSUM` (exit 1, never retried). Then a rename, unpacking with the system `tar` (xz, gz and zip on Linux, macOS and Windows 10+), a check that every binary exists, and a rename into `<data>/tools/<name>/<version>/`. It never uses sudo and never touches shell profiles.
- FFmpeg order: `SCRIPTVOX_FFMPEG`, then the pinned build if installed, then the system FFmpeg with `--use-system` (now a global flag), then the pinned download. A pinned build whose `configuration:` has `--enable-nonfree` is removed and refused (`SVX_NONFREE_FFMPEG`). `media add` never downloads.
- uv order: `SCRIPTVOX_UV`, then the pinned uv if installed, then uv on PATH, then the pinned download. The worker gets `UV_NATIVE_TLS=1`, and `SSL_CERT_FILE` passes through.
- `scriptvox setup [--dry-run]`: lists or downloads the pending pins with their bytes and licence.
- Agent mode: when a run would download more than 200 MB, `make` gives exit 10 with `kind:"download"` and the `--use-system` alternative, before any download.
- Tests (`tests/provision.rs`, local HTTP server): a good pin installs once (the second setup makes 0 requests), a bad sha256 is refused with no `.part` left, a nonfree build is refused, HOME profiles are byte-identical with no new files, the worker env has `UV_NATIVE_TLS=1`, and an agent run with a 300 MB pending download gives exit 10.
- Live: `scriptvox setup` downloaded, verified and unpacked the real 152 MB pin in 17 s.

Deferred: `plan --json` download bytes (RVX-026 adds `plan`), `setup --bundle` (offline), and an fs4 lock for concurrent first runs (today a rename race is resolved by the second rename).

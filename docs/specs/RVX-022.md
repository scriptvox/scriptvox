# RVX-022: self-discovery

- `scriptvox providers`: each HTTP row with kind, site, key variable name, `key_set` (never the value), network, cost and `output_terms`.
- `scriptvox tools`: the engine (FFmpeg, pinned licence), `tts.edge` (terms, timing) and the stock rows. The worker is not started.
- `scriptvox voices [--lang ar]` and `scriptvox templates` (from RVX-010 and RVX-005).
- `tools` takes a generator row's `cost` from `Generator::paid()` and its `network` from the gateway, so a local row says free and no network, as `providers` does. Self-hosted GPU rows are listed by `providers` only.
- Tests (`tests/discovery.rs`): every provider has `output_terms`, `--lang ar` lists only Arabic voices, and insta snapshots lock providers, Arabic voices, tools and templates. The tests clear key variables, so snapshots do not depend on the machine.

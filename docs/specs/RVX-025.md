# RVX-025: briefs and schemas

- `src/brief.rs`: the brief, one JSON file per video (`script` or `script_file`, lang, tts, voice, duration, aspect, media, stock terms, music). Unknown fields are refused (a typo like `voise` fails loudly). Paths are relative to the brief. `make --brief f` loads it, and CLI flags override its fields.
- `scriptvox schema brief|result|event`: JSON Schema generated with schemars from the Rust types (`Brief`, `Envelope`). The event schema is the hand-written `schemas/event.json`.
- `just schemas` regenerates `schemas/*.json`. CI fails when a committed schema is stale.
- Compatibility gate: `schemas/released/result.json` is the released `scriptvox.result/v1`. A property removed from the current result schema fails CI ("a removal needs result/v2"). Adding a field is allowed.
- `recipes/`: 6 briefs (Arabic explainer, own-media reel, stock short, timed 30 s, wide explainer, square quiet). A test loads each one.
- Tests: schemas fresh, no removed result field, 6 valid recipes, unknown field refused, and `make --brief` with `--aspect` override renders 1920x1080.

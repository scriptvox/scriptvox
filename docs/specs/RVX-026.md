# RVX-026: plan, approval, ledger and spend cap

> 5 Nov 2026: `--commercial` is deleted (`docs/specs/commercial-note.md`). Text below about it is history.

Pattern from MoneyPrinterTurbo `mpt_agent.py` (MIT): one token replaces a set of charge flags. OM #723 (an inert budget) and #636 are the ideas behind the code-enforced cap. Open question Q12 (default cap) uses the recommended default, $0: a paid stage always needs approval.

- `src/plan.rs`: a plan has stages (voice, stock, render, check; each with tool, cost, network, explain), the cost and the pending downloads. `plan_id` is `p_` plus blake3 over the script, language, voice, duration, aspect, media, stock, music, `--commercial`, the cap and the tool pins.
- `make --plan`: prints the plan and runs nothing (no download, no TTS).
- Approval: a plan with cost 0 runs at once. A paid plan without `--approve <plan_id>` gives exit 4 `approval_needed` with `next`. A stale token (the plan changed, so it has a new id) also gives exit 4 and says so.
- Ledger (`state.db`, Rust only): before a paid stage, `reserve` runs under `BEGIN IMMEDIATE` and checks the run's reserved and committed spend against the cap (`--max-spend`, default the approved cost). An overrun gives exit 4 `SVX_SPEND_CAP`. After the stage, the estimate is committed on success and released on failure.
- `--commercial`: refuses rows whose terms forbid commercial use (Edge), with exit 10 and only commercial engines as alternatives. `registry/voices.toml` has a `commercial` field and an ElevenLabs price estimate (`usd_per_1k_chars`).
- `--idempotency-key k`: the run id is `r_` plus blake3(plan id, key). A finished run is returned (`idempotent: true`) with no new work while its video is on disk. With the video gone, the run is made again under the same id. An unfinished one is attached and resumed (cache and chunks). `make --detach` uses the same id, and a generated scene with no key gets the id from the plan: a live supervisor answers `running`.
- `resume` makes a child run `<id>.N`. Before a paid submit, a child looks in the other folders of its family for a job or a submit of the same request (`genjob::adopt`). An open job is copied and polled; a marker stops at exit 6 and names the parent's file. `resume` refuses a parent that is still running (exit 2).
- Tests: same inputs give the same plan id, and a $0 plan runs without a token; a paid plan gives exit 4, a stale token gives exit 4 "changed", and the right token passes; 2 parallel reserves of $0.60 against a $1.00 cap: exactly 1 passes; `--commercial` refuses Edge; the same key returns the same run while the stub would fail new work.

Deferred: the "drift to a paid fallback gives a new plan_id" test needs a second paid engine (after RVX-028). A separate `scriptvox plan` verb is not added; `make --plan` covers it.

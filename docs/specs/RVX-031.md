# RVX-031: scriptvox licenses

- cargo-about 0.9.3 (prebuilt binary in `~/.cargo/bin`) generates `licenses/THIRD_PARTY.md` from `about.toml` and `licenses/about.hbs` (`just notices`): every licence with its full text and the crates that use it.
- `src/licenses.rs` embeds that file and the OFL text. It lists the components that are not crates: the embedded Noto fonts (OFL-1.1), FFmpeg (GPL-3.0-or-later, downloaded, never bundled, with the source location), edge-tts (LGPL-3.0, unmodified, through uv) and uv (MIT or Apache-2.0).
- `scriptvox licenses [--full] --json`: the project licence, 141 crates (`name version`) and the components. `--full` adds the notice and OFL texts.
- Test: every crate in `cargo tree -e normal,build -p scriptvox` (119 lines) is in the embedded notices, so stale notices fail CI ("run `just notices`"). Also, OFL and the FFmpeg GPL entry are present.

Simplification: the ticket named `build.rs`. A committed, generated file plus a staleness test does the same job without running cargo-about at every build.

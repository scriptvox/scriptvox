# RVX-032: skill, plugin, AGENTS.md, README, CREDITS

- `src/skill.rs`: the Claude Code skill is generated by the binary (`scriptvox skills render`). The steps and rules are fixed text, the brief fields come from the brief schema, the commands and their help from clap, and the exit table from `exit.rs`. It is 85 lines and version-stamped. `just docs` writes `plugin/skills/scriptvox/SKILL.md`, and a test fails when the committed file differs. So changed help text without regenerated docs fails CI.
- `scriptvox skills install` writes `~/.claude/skills/scriptvox/SKILL.md`. `doctor` warns when the installed skill version differs from the binary (fix: `scriptvox skills install`, `fix_safe:true`).
- `scriptvox init --agents` appends an 8-line scriptvox block to the project's AGENTS.md, once.
- Plugin: `plugin/.claude-plugin/plugin.json`, our own SVG icon, and `plugin/skills/scriptvox/`. The root marketplace (`.claude-plugin/marketplace.json`) points to `./plugin`. The plugin is in its own folder because the repo's CLAUDE.md (contributor context) must not sit at the plugin root. There is no `.mcp.json` (v0.2). `claude plugin validate --strict` passes for the root and for `plugin/`, also with `scriptvox` absent from PATH, and runs in `just check` when the claude CLI exists.
- Docs: README (line 1 from the plan, an executable quickstart, only features that work today), AGENTS.md (contributors: CI, DCO, the idea-reuse rule, provenance; users: 3 lines), CLAUDE.md (`@AGENTS.md` only), CREDITS.md (prior art as ideas only, reused code with attribution, components), TRIAGE.md.
- `evals/`: 4 prompt cases (English short, Arabic short, missing paid key, no trigger). They are run by hand, because they cost model calls.
- Tests (`tests/docs.rs`): the skill is fresh and under 160 lines (150 until 13 Nov 2026); the README `# exec` block runs (`--version`, `doctor --offline`, `demo`, `voices --lang ar`); `init --agents` adds its block once; doctor warns about a stale skill.
- The skill is not installed into this machine's `~/.claude`. That changes the owner's Claude setup, so it waits for the owner.

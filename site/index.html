SCRIPTVOX  /  OPERATION MANUAL  /  VERSION 0.1.0

A script goes in.
A narrated, captioned video comes out.

ScriptVox is a command-line tool. You can use it directly, or a coding agent such as Claude Code can operate it for you.

you     make a 30 s vertical short in Arabic about dates, free tools only
agent   scriptvox plan, make --detach, wait, snapshot
result  scriptvox-out/r_7f3c9a.mp4, 30.0 s, $0, -14 LUFS, all gates passed

4Installation

NOTE: There is no published release at this time. The commands below become available at the first release.

  1. Install ScriptVox.
  2. Run the test. It renders a video of 8 seconds with no keys, no Python and no Node. 
    scriptvox demo
  3. Make your first video. 
    echo "ScriptVox turns a script into a video." > script.txt
scriptvox make --script script.txt --music calm

On first use, ScriptVox downloads a pinned FFmpeg build into its data folder and checks its sha256. The installation runs without sudo and makes no change to your shell profile.

5Operation by an agent

With --json, each command prints one JSON document with fixed exit codes and a fix line. Most commands are also available as MCP tools.

1scriptvox plan --brief brief.json --jsonThe cost and a plan_id. Nothing runs
2scriptvox make --brief brief.json --detach --jsonA run_id. The run continues in the background
3scriptvox wait <run_id> --jsonThe result, with the path of the video
4scriptvox check <run_id> --jsonOne row for each quality gate

CAUTION: An agent must not approve a plan by itself. The approval belongs to the person.
